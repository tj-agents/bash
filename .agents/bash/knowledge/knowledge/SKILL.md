# Bash knowledge

Use the adopting project's learner record. This shared package stores no person's
competency or progress. Without a record, ask about the concepts relevant to the
lesson rather than inferring knowledge from existing code.

```bash
printf '%s\n' 'two words' '*'
# Ask the learner to explain argument boundaries before recording understanding.
```

## ✅ Fluent

Demonstrated understanding belongs in the learner's own record, not this package.

## 🟡 Met, shaky

Keep uncertainty in that same record. An explanation is not proof of understanding.

## Log

Progress belongs to the adopting project. Shared standards changes are not
learner-progress updates.
